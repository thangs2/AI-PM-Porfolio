00 — Overall landscape

One map of the AI TDM operating system: zones, components, in / out. Detail lives in mapping 01, architecture 01–09, cases 10–27, edges 30–52. This file is the picture you hold in your head.

Law (from 01): AI reads, classifies, drafts. Green auto-commits. Red returns to sender. PM owns exceptions + the rule. Nucleus is never the source of truth.

Cockpit is swappable. Diagrams below use Cursor as the default Zone 3. Company-Claude map: §3b and 02b. Zones 1, 5, 6 stay the same.

1. Zones (left → right)

Work enters on the left, gets judged in the center, lands on the right. People sit outside the nucleus: senders on the source side, pods and leads on the destination side.

Each zone is a vertical column. Happy path is left → right. Red bounce and quarantine curve back to the sender. Pod pulls Ready (never waits TDM); the Dept Head gets the status pack.

6. Three traffic patterns (the actual loops)

A — Green (happy path)

Sender / system → Zone 1 → MCP in → Nucleus + RAG cite → A–G pass + policy → auto Ready / /verified → Pod pulls. TDM is not in the loop. Sample later.

sequenceDiagram
  participant S as Sender / Drive / Jira
  participant MCP
  participant N as Nucleus
  participant G as Gate
  participant D as Destination
  participant P as Pod

  S->>MCP: artifact
  MCP->>N: bytes + metadata
  N->>N: RAG cite + A-G
  N->>G: VERIFIED + policy OK
  G->>D: auto Ready / /verified
  P->>D: pull
  Note over N,G: TDM not here

B — Red (bounce to sender)

Missing A–G → Needs_AC assigned to sender + SLA. Re-score. Auto Ready if now green. TDM still not here unless bounce ≥ 2 / dispute / SLA miss.

sequenceDiagram
  participant N as Nucleus
  participant J as Jira
  participant S as Sender
  participant TDM

  N->>J: REWORK + reason codes
  J->>S: Needs_AC SLA 24-48h
  S->>J: fix
  N->>J: re-score
  alt green + policy
    J->>J: auto Ready
  else still red
    J->>S: still Needs_AC
  else dispute / bounce≥2
    S->>TDM: exception queue
  end

C — Yellow (PM exception)

P0, CONFLICT, PII, new author, low confidence, SoW gap → pm-review. TDM stamps or bounces. Then destination same as green.

Pods never wait on C to pull a green ticket sitting in Ready.
